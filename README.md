# NLP Automation System

A modular Natural Language Programming Interface that allows users to interact with their computer using natural language.

## Current Features

- Natural language command interpretation
- Gemini LLM integration
- Provider-agnostic architecture
- JSON-based command schema
- Schema validation
- Command preview

## Tech Stack

- Python
- Google Gemini API
- JSON
- Modular Architecture
